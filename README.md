# SensorOmen

Collects and displays real-time sensor data from various devices, a unified view for facilities managers and maintenance personnel.

The key benefits of using SensorOmen include:

- Collects and displays real-time sensor
- data from various devices, a
- unified view for facilities managers

## Key Features

- Collects and displays real-time sensor

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/SensorOmen.git`
2. `cd SensorOmen`
3. Install in editable mode: `pip install -e .`

## Configuration

SensorOmen is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
